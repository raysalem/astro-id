## Brief
astro-id plate-solves night-sky photos and names what is in them: constellations, Messier/NGC/IC objects, named stars, Sun, Moon and planets, each with a 0-100 confidence. `astro-id moon` names the maria, craters, ranges and Apollo sites on a Moon close-up.
It is for photographers who shoot the sky on a tripod and want to know what they caught, with or without the Facet photo library.
It runs ASTAP on each photo, refits the frame, and identifies objects against reference catalogs. It is not a telescope controller, a stacker or a star-chart app.

| Part | Folder | Job |
|---|---|---|
| Engine | `astro_id/` | solve, identify, score, quality, cull, labeled copies; `label`, `check`, `session` commands |
| Moon | `astro_id/moon.py`, `moon_catalog.py` | `astro-id moon`: disc fit, phase, orientation, lunar names |
| Facet add-on | `astro_id/facet/` | self-updating keeper, panel server, save and undo over Facet's MCP/HTTP API |
| Panel page | `astro_id/facet/static/` | the sandboxed Astro panel (HTML + bridge) |
| Facet plugin notes | `facet_plugin/` | the removed in-process plugin, kept as a notifier example |
| Tools | `tools/` | docs check; example, demo and Moon catalog builders |
| Tests | `tests/` | Python suites, Node panel/bridge tests, live scripts |
| Examples | `examples/` | five sky frames and four NASA Moon frames with expected results |

Docs: decisions and gotchas in `docs/DETAILS.md`; bugs in `docs/ISSUES.md`; plans in `docs/plans/`; users start at `README.md` and `docs/USAGE.md`; every option in `docs/REFERENCE.md`; interfaces in `CONTRACT.md` and `ANNOTATIONS.md`; suites and CI in `docs/TESTING.md`.

## Commands
Run from the repo root. Python 3.12, uv, Node 22.

| Do | Command |
|---|---|
| Install | `uv sync` (CI: `uv sync --frozen`) |
| Test (Python) | `uv run pytest -q` (add `-rs` to see what skipped) |
| Test (panel, Node) | `node --test tests/js/bridge.test.js` and `node --test tests/js/panel.test.js` |
| Docs links and personal text | `uv run python tools/check_docs.py` |
| dev-notes check | `python dev-notes/tools/check.py` |
| Requirements on this machine | `uv run astro-id check` |
| CI by hand | `gh workflow run ci.yml --ref <branch>` |

No linter or type checker is configured.

## Repo-specific rules
- The Facet add-on restarts itself when files in a checkout it runs from change: do all work in a branch or worktree, never in the checkout the owner runs.
- Keep this repo public-safe: no personal paths, private addresses, real library paths, photo file names or names in docs or tests. Example photos are not MIT (see `examples/README.md`).
- `astro_id/moon_catalog.py` is generated by `tools/make_moon_catalog.py`; do not edit it by hand.
