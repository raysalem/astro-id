# plans: one file per task

Each task gets its own plan, named by date and slug (`2026-01-31-fix-login.md`), copied from `dev-notes/templates/PLAN.md`. Its first lines carry the status: `in progress`, `blocked (why)` or `done` with a date.

- Write the plan before you edit code. Two sessions never share a plan file, so parallel work does not collide.
- Finished plans stay here: this folder is also the archive.
- Before you start, read the plans that are still open. If one names the files or symbols you need, talk to its owner first.
